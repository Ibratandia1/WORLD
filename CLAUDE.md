# World — notes pour Claude

Jeu mobile de simulation de vie (travailler, voyager, acheter, devenir riche ou pauvre).
Décisions par événements. Départ à Paris : vrais quartiers, commerces et marques aux noms **inventés**.
Solo d'abord, puis multijoueur où de vrais joueurs remplacent des PNJ (côté jeu de rôle).
L'utilisateur parle français : répondre en français, textes du jeu en français.

## Décisions fixées
- **Plus de moteur 2D (Phaser retiré le 2026-11-17)** : tout l'affichage est en Three.js (`city3d.js` ville, `interior3d.js` intérieurs), sans bundler (importmap CDN), pensé mobile tactile ; emballage Google Play plus tard (Capacitor). Les notes plus bas qui parlent de GameScene / InteriorScene / FxScene / render.js / festdecor / camera.js / iso.js / `?2d` décrivent l'ancienne 2D : ces fichiers n'existent plus.
- Boucle : `city3d.js` appelle `opts.onFrame(ms)` à chaque image → `GameController.update` (`src/game/game.js` : `world.update`, feu rouge, ouverture des intérieurs, `state.ui.update`). `state.scene` = GameController (tapTile, useSpot, `spots` = `streetSpots`, `fest` = `FestSpots`, floatText / focus → city3d). `state.interior` = `InteriorLogic` (`src/game/interior.js` : étages, boutons `#floors`, places des habitants `views`, `ctx3d()`, `tapTile3d`, `useItem`). Outils partagés : `src/city/common.js` (rng, cityPulse, streetSpots, FestSpots). Three.js introuvable → écran `#nogl` « Réessayer ».
- Écran paysage, grande carte isométrique, barre d'icônes **sans texte** en haut, événements dans une petite fenêtre en bas à droite.
- **Règle d'or** : joueur et PNJ utilisent les mêmes actions. Tout passe par `world.perform(actor, id, params)` ; un acteur ne diffère que par `controller` (`player` / `ai` / plus tard `remote`). Ne jamais ajouter d'effet de jeu qui contourne `ACTIONS`.
- Carte : grille texte (actuel) → Tiled → génération OpenStreetMap. `parseMap` produit le format commun.

- **Deux quartiers** : le Marais (rangs 0–29) = centre-ville (immeubles, commerces, services) ; au sud, **les Jardins** (rangs 30–47, ajoutés le 2026-11-17) = quartier résidentiel : 12 maisons + 2 villas (`type: 'home', style: 'house'`, 1 logement, plan intérieur `LAYOUTS.house` sur 2 étages), grand parc des Glycines (allées `p` gravier, étang `e` sol `pond` avec canards, aire de jeux `k`, fontaine), jardins privés `j` (haies côté rue, massifs), petits commerces `style: 'village'` (Café du Parc, Boulangerie des Jardins, 3 étages en 3D). Rendu : `house()` dans city3d.js (toit de tuiles à 4 pans, volets, porte côté rue, boîte aux lettres). Actions `feed_ducks`, `play_swing` (toucher l'étang / l'aire de jeux). Le toit `mansard()` avait ses pans à l'envers (corrigé : immeubles mieux éclairés). Nouveaux lieux toujours ajoutés en fin de `order` (ids stables) ; les rangées s'ajoutent EN BAS (coordonnées du Marais inchangées, pas besoin de changer `layout`).

- **Déplacements (2026-11-17)** : marche `WALK` = 1,1 case / min de jeu (traverser la carte ≈ 1 h de jeu). Véhicules (`catalog.js`) : `mode: 'bike'` (trottinette ×1,6, vélo ×2,1 : piste cyclable, au pas ×1,35 max sur le trottoir) ou `'motor'` (scooter ×3, voiture ×3,8 : vraie vitesse seulement sur la chaussée, à pied jusqu'à la porte). `findPath(map, start, isGoal, mode)` : coûts par mode (`COSTS` dans pathfinding.js). `world.speedOn` ; véhicules arrêtés AVANT le passage piéton au rouge (`a.waitLight = 'car'`) ; `a.riding` (transitoire) = sur son véhicule (3D : vélo / trottinette / scooter sous la personne, voiture à sa place, décalé sur sa voie). PNJ : départ au travail 60 min avant (`EARLY` = 80).
- Rues 3D : chaussée élargie de `RW` = 0,16 de chaque côté (le trottoir recule), pistes cyclables vertes avec pictogramme, voies `LANE` (voitures 0,24, vélos ≈ 0,55). Circulation de décor : voitures + cyclistes (`kind`), virages lissés, arrêt avant le passage piéton. Véhicules de secours (`dispatch` / `recall` dans city3d.js, `state.city3d.emergencies`) : pompiers + ambulance sur un incendie (`showFire` / `hideFire`), police sur `crime` (vu), `custody`, `arrested` ; partent de leur caserne / hôpital / commissariat par la chaussée (`roadRoute`), gyrophares, restent puis rentrent. Immeubles : palette `STONE` plus colorée, chaînes d'angle, dernier étage en retrait (`attic`, 1/3), toit-terrasse végétalisé (1/5), toits `mansard()` à l'endroit.

- **Caméra et toucher (2026-11-17)** : suivi du joueur (`setFollow` dans city3d.js, 🎯 allumé = `#b-center.on`) : en suivi, un doigt / clic gauche = tourner autour du joueur, deux doigts = zoom + déplacement (déplacer la vue à plus de 1,2 case du joueur coupe le suivi). Sans suivi : un doigt = déplacer. Boutons ⟲ ⟳ (`#b-rotl` / `#b-rotr`, `api.rotateBy`). Trajet du joueur : pointillés dorés instanciés (`routeDots`) + repère (`routeDest`). Toucher un lieu = y aller (`onPlace` dans main.js : entrer, sinon marcher jusqu'à la porte + fiche).
- **Postes** (jobs.js) : `POSITIONS[type]` (1er = poste d'entrée qui prend les places restantes ; `edu`, `cert`, `exp`, `pay`), `positionsOf(b)`, `posOf(w, job)` (`job.pos`), `freeSlots`, `qualifies`, `bestPosition`, `expOf` (`actor.exp[type]` = jours travaillés sans faute, +1 dans `reviewDay`). Formations `CERTS` (action `train` à l'école, `params.cert`, `actor.certs`). `apply` accepte `params.pos` ; postuler là où l'on travaille = promotion (événement `promoted`). Lieu sans aucune équipe : le gérant reçoit 9h–18h. UI : `jobsHTML(b)` (lignes à choisir + un bouton), `trainHTML(b)` à l'école. Anciens contrats rangés par `economy.assignPositions()`.
- **Économie** (`src/sim/economy.js`, `world.economy`, sauvegardée) : trésorerie des commerces (ventes × `CLIENT_SCALE` + clientèle de passage − salaires réellement versés (`paid`, depuis `incomeTax`) − marchandises − `FIXED`) ; pertes 3 jours + caisse < 600 → gel puis licenciement du dernier arrivé (`laidOff`) ; reprise → réembauche ; > 9000 € et clientèle → +1 poste (`cuts` = −1) ; vendredi > 7000 € → prime +1 €/h ; poste vide 4 jours → `wageBonus` +1 (max +3). Lundi : loyers `b.rentMul` (0,7–1,5) selon logements libres / sans-abri (`weeklyRent`), indice des prix `cpi` (dans `world.costOf`). `health(bid)` pour l'interface.

- **Personnages 3D** : `src/figure3d.js` (`figurePose(look, 'stand' | 'walk' | 'sit', frame)`, `FIGURE_MAT`, `WALK_FRAMES` = 6) : un seul maillage par personne (hauteur 1, `mesh.scale` = 0,4 dehors / 0,58 dedans), bras et jambes articulés (poses pré-calculées, mises en cache par apparence, jamais `dispose`), yeux, sourcils, nez, bouche, oreilles, 11 coiffures, silhouettes, tenues (robe, marinière, costume + cravate, veste, sweat), chapeaux, lunettes, moustache, écharpe. Passants de décor : 12 apparences types (`WALKER_LOOKS`).
- **Téléphone** : anticrénelage matériel partout, résolution adaptative (`pixelRatio` entre `PR_MIN` et `PR_MAX`, ajustée toutes les 2 s selon les images/s), ombres recalculées seulement quand le soleil avance (pas de 10 min de jeu, `lastSunH`) ; liserés et gyrophares adoucis. Caméra : `rotateSpeed` 0,45 au doigt (0,6 souris), `zoomSpeed` 0,7, amortissement 0,12.
- **Sons** : oiseaux synthétisés réalistes (`chirp` avec vibrato, filtre, panoramique : merle, mésange, moineau), rares (chœur le matin, moins l'hiver). Annonces : silence pour le banal (`QUIET` dans ui.js : journal, salut, faim, fatigue, réveil, fête, tuyau), petit `pop` pour une info, carillon pour l'important (`BIG`). Les événements poussés portent `kind`. Erreurs : seulement à ta demande (pas la routine), 1 / 2,5 s ; pièces : gains ≥ 5 €, 1 / 4 s.

- **Chauffe du téléphone (iPhone 12)** : au téléphone, rendu plafonné à 30 images/s (`capDt` dans `frame()` ; 20 en économie de batterie), résolution fixe 1,15× (pas de remontée), 8 voitures et 5 passants au plus ; la simulation avance quand même à chaque `requestAnimationFrame`. Personnages préparés peu à peu (4 par image, seulement ceux dehors). `state.city3d.slow` liste les images de plus de 40 ms (par partie : voitures, gens, rendu, décor, jeu). ⚠ Mesurer les images/s seulement avec le panneau d'aperçu VISIBLE (masqué → 1 image/s).
- Fiche d'un commerce : pastille 📈 « Les affaires marchent » / 📉 « En difficulté » (`economy.health`). « Ma vie » : section « Ma carrière » (diplôme, formations, expérience par métier).

- **Meubles** (`src/sim/furniture.js`) : `FURNITURE` (plante, tapis, lampadaire, fauteuil, bibliothèque, canapé, aquarium, console, piano, grand lit), `actor.furniture` [{id, x, y, floor}] (sauvegardé, `furnHome`, `stored` = garde-meuble), placement auto `placeFor` (contre les murs, pas sur portes / postes / escaliers), `ensurePlaced` au déménagement, `furnishedFloors` (InteriorLogic les ajoute au plan de TON logement ; événement `furnished` → `reload()`, `ctx.rev` force le redessin 3D). Actions `buy_furniture` / `sell_furniture` (40 % du prix) / `watch_fish` / `play_games` / `play_piano`. Confort `comfortOf` (max 40) : moral +0,00025 × confort / min chez soi ; `sleepBoost` (grand lit +25 % d'énergie en dormant). UI : `furnHTML()` dans la fiche de ton logement (🛋️ Catalogue). Nouveaux meubles 3D : floorlamp, aquarium, gameconsole, piano.
- **Salle de sport** : « Salle de sport Énergie » (lettre W, type `gym`, id 46, rangs 23–25 colonnes 22–24 au bord du square, ex-immeuble de décor). Horaires 7h–22h (2 équipes), postes : hôte·sse d'accueil / coach (formation `coaching`) / gérant·e (20 j d'exp.). Actions `workout` (8 €, 1 h) et `yoga` (6 €). `actor.fitness` 0–100 : jusqu'à 25 % de fatigue en moins, −1 / jour sans sport. PNJ : séance de temps en temps avant / après le travail. Plan `LAYOUTS.gym` (cardio, musculation, yoga, accueil), machines 3D : treadmill, exbike, weightrack, benchpress, yogamat, lockers.

- **Années** (`src/sim/calendar.js`, `world.calendar`, créé après Economy) : une année = 4 saisons = 56 jours (`world.year`, `world.dayOfYear`, `YEAR_DAYS`). Chaque habitant a `age` et `birthday` (jour de l'année, donnés par `ensureAge` : âge crédible selon le métier ; joueur 25 ans) ; anniversaire = +1 an, événement `birthday` (joueur : « Fêter mon anniversaire » `birthday_party`, 30 €, amis ❤ +6 ; amis du joueur : nouvelle du journal + `wish_birthday` sur leur fiche). Retraite des PNJ à 65 ans (`retired`, pension 220 €/sem. le lundi, budget `pensions` ; les retraités ne cherchent plus de travail). Nouvel An : `newYear` + `yearRecap` (argent gagné depuis `yearStart`, XP, amis proches) + feu d'artifice (city3d `updateFireworks`, dernier soir 23h30 → 0h40, au-dessus des toits devant la caméra, étincelles `sparkTex`, son `boom` via `opts.onBoom` ; test : `state.city3d.fireworks()`). Barre du haut : « Lun 🌸 An 2 ». ⚠ calendar.js n'importe pas world.js (boucle d'imports) : SEASON_DAYS recopié.

- **Styles d'immeubles** (city3d.js) : `styleOf(seed)` pour les immeubles ordinaires (logements nommés + immeubles de décor) : 45 % haussmannien (façade d'origine, balcons, Mansart + lucarnes, chaînes d'angle, étage en retrait), 20 % `old` vieille pierre à volets (4–5 étages, toit d'ardoise à deux pans `gable()` + lucarnes), 15 % `brick` brique rouge d'atelier (verrières, toit plat à muret, château d'eau ou verrières en dents de scie), 10 % `timber` colombages (3–4 étages, encorbellement, toit de tuiles pentu), 10 % `modern` (6–8 étages, grandes baies, dalles en bandeau, toit plat : terrasse végétalisée ou climatiseurs). Textures dessinées par le code `STYLE_DRAW` (+ fenêtres allumées la nuit), un matériau par style `STYLE_MATS` (4 appels de dessin en plus en tout). Pignons des toits à deux pans dans `roofGeos` (non indexés). Services publics et commerces gardent leur aspect.

- **Structure des immeubles** (city3d.js) : `plainBuilding()` coupe les grands immeubles ordinaires (2 cases ou plus, sauf colombages, 2 sur 3) en deux corps de hauteurs différentes (±1–2 étages, même style ; `r.ref` = emprise entière en cases, les corps se chevauchent de 0,04 pour ne pas laisser de fente). `building(..., styleOverride)`. Façades : bandeaux de pierre à chaque étage (haussmannien, vieille pierre), bow-window côté rue (1 sur 4, 4 étages et plus), porte d'entrée avec encadrement côté rue (immeubles sans boutique au rez-de-chaussée ; marquise vitrée pour le moderne).

## Architecture
- `src/sim/` : simulation pure JS, **aucune dépendance à Phaser ni au DOM** (pour tourner un jour côté serveur).
  - `actions.js` catalogue des actions · `world.js` temps (jour 1 = lundi), météo, déplacements · `ai.js` choix des PNJ **et** routine auto du joueur
  - `jobs.js` contrats (service de 8 h, jours travaillés, avertissements → renvoi au 3e, augmentation tous les 10 jours sans faute, candidatures)
  - `housing.js` loyer hebdo le lundi, relance à 4 j de retard, expulsion à 8 j, location / achat
  - `social.js` relations 0–100 entre habitants, proximité, répliques des PNJ selon leur situation
  - `events.js` événements **contextuels** (aucun tirage purement aléatoire) + conséquences poussées par le monde ; délai mini entre deux événements
  - `people.js` habitants de départ
- Rythme : 1,5 min de jeu / s ; pendant une action du joueur le temps accélère selon `skip` (travail ×6, sommeil ×16).
- `src/map/` : `quartier.js` (grille texte du Marais, tracé organique), `types.js` (apparence par type de lieu), `parse.js`
- `src/scenes/GameScene.js` : rendu iso (textures générées), toucher → action ; bascule vers l'intérieur quand `player.inside` change
- Intérieurs : **dessinés par le code, en un seul plan structuré par étage** (l'utilisateur a refusé les illustrations « trop IA » ; `assets/interiors.webp` n'est plus utilisé). Filtre pixel art (`PIXELATE` dans InteriorScene) sur la caméra de la pièce ; une 2e caméra affiche les étiquettes nettes (calques `worldLayer` / `uiLayer` : tout nouvel objet doit aller dans l'un des deux via `w()` / `u()`).
- Étages : un plan peut avoir `floors` (bureau : RDC accueil + cafétéria, 1er open space, 2e réunion + direction ; logement : hall + appartement). Boutons d'étage à gauche, la vue suit l'étage du joueur, le socle montre la façade des étages inférieurs.
- Écran d'accueil (`src/start.js`) : Continuer / Modifier mon personnage / Nouvelle partie ; sans sauvegarde, la création du personnage s'ouvre directement.
- HUD (pensé mobile paysage, rien ne se superpose ; icônes SVG dans `src/icons.js`) : en haut à gauche l'essentiel (heure, météo, argent, jauges) ; barre `#dock` EN BAS À GAUCHE, en ligne (frigo, travail, logement, 🚪 sortir, 🎯 recentrer — demandé par l'utilisateur, qui préférait cette place) ; étages au milieu à gauche ; en haut à droite le temps (pause, vitesse, son, plein écran) et en dessous la colonne `#side` (plan, habitants, routine, tenue) ; fenêtre `#box` en bas à droite décalée de la colonne ; carte d'objectif à droite de la colonne gauche (réduite par défaut sur petit écran) ; étages en bas à gauche. Les événements ont une ✕ (`data-evclose`).
- Couleurs des bâtiments : `GameScene.lookFor(b)` — chaque logement a sa façade (`FACADES`), les commerces la teinte de leur métier (`SHOP_TINT`), toits variés (`ROOFS` : zinc, ardoise, tuile, cuivre) ; les immeubles de décor piochent dans les mêmes palettes. Arêtes marquées entre deux bâtiments voisins (fin de `drawBuildingTile`).
- Couleurs de l'interface : `#box[data-theme]` (type du lieu ou du panneau, posé dans `UI.render`) colore le bandeau d'en-tête ; boutons colorés par catégorie d'action (`ACT_CAT` dans ui.js → classes `c-food`, `c-work`, `c-rest`, `c-social`, `c-money`, `c-civic`, `c-danger`) ; HUD et colonnes teintés. Fiche d'un lieu (dehors ou dedans) : `#box.wide` = fenêtre compacte en paysage (≈ 50 % de la largeur), à la même place, boutons en grille ; le poste à pourvoir en bandeau tout en haut (`.jobtop`), « Sortir » pleine largeur tout en bas (`.leave`).
- Intérieurs : TOUS les meubles sont touchables. Sans action définie → menu d'usages génériques (`genericActions` dans InteriorScene : s'asseoir, regarder, arroser, en-cas au distributeur, eau, feuilleter un livre ; actions `inspect` (texte `ITEM_FLAVOR`), `sit_here`, `vending_snack`, `drink_water`, `browse_books`, `water_plant`) ; `showObject` accepte `params`.
- Bulles des lieux : `GameScene.declutter` (toutes les 250 ms) masque celles qui se chevauchent (priorité : chez toi / ton travail > services et commerces > logements libres ; dézoomé : seulement les tiennes). `c.base` = visibilité de base.
- Performances : `GameScene.cull` masque immeubles, décor, lampadaires et morceaux de sol (8×8 cases) hors écran (`scene.cullables`, `hull.box`) ; résolution plafonnée à 2× (DPR).
- `src/city/render.js` : rendu détaillé de la ville (façades, balcons, toits, ombres, trottoirs, passages piétons, lampadaires, terrasses, fontaine, voitures décoratives, fenêtres allumées la nuit).
- `src/scenes/InteriorScene.js` + `src/interiors/` : intérieurs détaillés (plans par type dans `layouts.js`, meubles dans `furniture.js`). Les PNJ présents occupent des « stations » selon leur action ; toucher un meuble lance son action.
- Entrer / rester / sortir : actions `enter`, `stay` (état après une action), `leave`. `actor.doing` = action réelle (null si juste « sur place »).
- ⚠ `actor.inside` peut valoir 0 : tester `actor.outdoors`, jamais `!actor.inside`.
- `src/look.js` + `src/customize.js` : apparence pixel art (16×28) et éditeur de personnage, profil sauvé dans localStorage (`world.profile`).
- `src/camera.js` : glisser / pincer / toucher, partagé par les scènes
- Sauvegarde : `src/sim/snapshot.js` (photo JSON du monde, sans stockage — réutilisable côté serveur) + `src/save.js` (localStorage `world.save`, toutes les 10 s, à chaque jour, en quittant). Ajouter tout nouvel état d'acteur à `ACTOR_FIELDS` et augmenter `SNAPSHOT_VERSION` si le format change.
- `src/ui.js` : HUD et fenêtre d'événements en HTML par-dessus le canvas
- Lancer : `npm start` → http://localhost:5173 (serveur `server.mjs`, config preview : `.claude/launch.json`)
- Rendu net : le canvas est à la résolution réelle de l'écran (`state.dpr`, `scale.zoom = 1/dpr`). Les marges d'interface en pixels CSS doivent être multipliées par `state.dpr` côté Phaser.
- Boutiques : `src/sim/catalog.js` (tenues, chapeaux, véhicules, smartphone) ; action `buy` (en boutique), `use_vehicle`. Véhicule = vitesse ×N dans la rue + assurance le lundi. Maison Plume (Y) et Garage Roue Libre (V) dans la rue ajoutée au sud.
- Métiers : `role` des habitants (manager, landlord, police, postman). Métiers de rue = `job.street` (tournée, payés dehors pendant le service). ⚠ Nouveaux habitants et bâtiments toujours AJOUTÉS À LA FIN (ids stables pour les sauvegardes).
- Conversation libre : `src/chat.js` (fiche du PNJ + réponses intégrées hors-ligne + application des actions via `world.perform`) et `server.mjs` (`POST /api/chat`, SDK Anthropic, `claude-opus-5-5`, sortie JSON structurée, effort low, fallback serveur). Sans clé : 503 → réponses intégrées.
- Oiseaux et pigeons : `Birds` dans `src/city/render.js`.
- Discussions : `talk` fait s'arrêter l'autre (`listen`, si `canPause` : pas au travail, pas juste avant son service). Bulles `actor.bubble` (+ `bubbleHold`) affichées sur la carte et en intérieur. Ouvrir la fiche d'un PNJ ou lui écrire l'arrête (`engage` dans chat.js).
- Rythme : 1 min de jeu / s (journée ≈ 24 min), marche 1,6 case / min de jeu. Pas de filtre pixel dans les intérieurs (flou).
- Nuit : fenêtres / vitrines (calque `lg` par bâtiment), halos et flaques de lumière des lampadaires (blend ADD), voile de nuit DOM limité à 0,34.
- ⚠ Tests : utiliser **http://localhost:5173/?test** (partie neuve jamais sauvegardée). Sans `?test`, c'est la vraie partie de l'utilisateur.
- Pas de noms ni de bulles au-dessus des têtes (demande utilisateur) ; le joueur a une flèche + un anneau jaune au sol.
- Personnages : dessin 16×28 + contour → textures 18×30. Contour « doux » (teinte sombre de chaque pixel, `mixDark`), visage avec volume, oreilles, sourcils, reflet des yeux, nez ; cheveux en 2 tons. 11 coiffures (dont afro, queue, carré, tresses) et 3 silhouettes `look.build` (mince / normal / fort, `BUILDS`). Images : debout, `_1` `_2` (marche de face), `_i` (respiration au repos), `_b0` `_b1` `_b2` (de dos quand on s'éloigne : `actor.away`, calculé dans world.move). `drawCharacter(look, rect, pose)`.
- Façades transparentes : `GameScene.updateOcclusion` rend transparentes (28 %) les cases d'immeuble devant le joueur (hulls avec g / d / lg ; la nuit est réappliquée dans `syncLights`).
- Poses façon Sims (intérieurs) : `POSES` dans look.js (assis, vu de dos, livre, poêle, tasse, fourchette, clavier), créées à la demande par `ensurePose`. `poseFor(action, station)` dans InteriorScene ; stations avec `seat`, `pose`, `table`, `lieAngle`. « Cuisiner » = phase `cook` aux fourneaux puis repas à table. Effets : écran de télé, vapeur, Zzz, assiette. ⚠ « cook » n'est pas une action : toujours prévoir un repli quand on lit `ACTIONS[act]`.
- Les PNJ ne doivent pas importuner le joueur : ils ne lancent jamais de discussion avec lui ; l'événement « salut » est rare (amis seulement, 1 fois / 3 jours / personne) ; délai mini entre événements 120 min.
- Moral (`actor.mood`, jauge 😊) : s'use avec le travail, les dettes, la faim, l'absence de logement ; remonte avec discussions, loisirs (télé, livre, banc), repas, cadeaux. Influence l'embauche et l'énergie ; événement « Coup de blues » ; la routine et les PNJ se détendent quand il est bas.
- Interactions : PNJ (saluer, plaisanter, cadeau, café, balade — débloqués par la relation), objets d'intérieur à plusieurs usages (`actions: [...]` dans layouts.js → menu), objets de rue (bancs, fontaine, pigeons via `scene.spots` / `birds.pigeons`) avec « Y aller » si trop loin. Cadeaux = articles `consumable` de la supérette (`actor.gifts`).
- Git : dépôt initialisé (branche main). Le dossier « game world » (autre dépôt vide de l'utilisateur) est ignoré. Objets de rue / stands : `GameScene.useSpot` (si loin : marche puis geste à l'arrivée via `player.afterGoto` + événement `arrive`). Fiche dans un commerce : Postuler + Sortir seulement, avec une astuce « Touche le comptoir ou un meuble ».
- **3D seule (anti-freeze)** : la ville est en 3D pour tout le monde (réglage `view3d` retiré ; `?2d` = secours / tests ; sans Three.js → rechargement en `?2d`). Phaser n'est plus dessiné du tout en 3D (scènes `setVisible(false)`, canvas masqué) : il ne garde que la logique. Boucle 3D incassable (`loop` → `frame` dans un try/catch : une erreur ne fige plus l'image). Ombres : `shadowMap.autoUpdate = false`, recalcul 1×/s (et à chaque nouvelle pièce) ; personnages, voitures et passants sans ombre portée. Téléphone : pas d'anticrénelage matériel, résolution 1,25×. Pluie / neige en 3D (`weatherPts`).
- Logique : embauche → `job.startDay = lendemain` (`isWorkday` ignore les jours avant : pas de service, de retard ni d'avertissement le jour même) ; l'événement « Embauché·e » propose « Commencer lundi prochain » (action `job_start_monday`). Postuler seulement quand quelqu'un est là (lieux `OPEN_HOURS_TYPES`). Refus logiques : manger sans faim, sieste en pleine forme, courses avec frigo plein. Événements retirés (jugés gênants) : portefeuille trouvé, vendeur de parapluies, ticket à gratter à la caisse, musicien de rue.
- Commerces vivants (city.js) : `promo(w, id)` (happy hour café 17h–19h −30 %, invendus boulangerie après 18h −40 %) intégré à `priceMul` (les PNJ en profitent) ; carte de fidélité (`actor.loyalty[bid]`, tous les `LOYALTY_EVERY` = 5 passages payants le dernier est remboursé, événement `loyalty`) ; plat du jour / spécialité (`dishOfDay`). Badges dans `miniPlaceHTML` (`.mp-chips`).
- Sons v2 : volumes séparés `musVol`, `ambVol`, `uiVol` (settings, appliqués dans `Sound.apply`), curseurs avec pourcentage dans ⚙️ → Son, bouton « Tester le son ». Sons des grands moments (`SFX` dans ui.js) : embauche `hired`, fidélité `sparkle`, amende / garde à vue `whistle`, verdict `gavel`, libération `unlock`, augmentation `fanfare`. Écran d'accueil v2 (start.js) : sous-titre, jour, pastilles (argent, logement, travail, saison), bouton ⚙️ Paramètres.
- **Moteur 2D sans affichage** : en 3D, Phaser démarre en `Phaser.HEADLESS` (aucun canvas, aucun WebGL, `game.renderer` = null) : il ne garde que la logique (boucle de jeu → `world.update`, UI, InteriorScene, FestDecor pour les emplacements des stands). Tout ce qui fabrique une texture 2D (`generateTexture`, `ensureCharTexture`, `ensurePose`) est évité dans ce mode : GameScene ne fait pas `makeTextures`, pas de FxScene ni de contrôles 2D ; InteriorScene utilise un objet vide `STUB` pour les sprites ; `FestDecor.person` ne crée pas de figurants. ⚠ Tout nouveau code 2D doit tester `scene.sys.game.renderer` avant de dessiner. La 2D complète ne revient qu'avec `?2d`.
- Anglais : vérification automatique (chaînes 'entre apostrophes' du code passées dans `t()`, et tous les événements déclenchés en anglais). Modèles ajoutés : jours abrégés (`Lun Mar` → `Mon Tue`), avertissement « Nom : « raison » phrase ». ⚠ Pas de guillemets typographiques dans une commande PowerShell (ils cassent la chaîne) : passer par un script Node ou l'outil d'édition.
- Épingles v2 : pictogrammes vectoriels blancs `PIN_GLYPHS` (icons.js) sur pastille de la couleur du lieu (plus d'emojis). Chez toi = épingle dorée agrandie + étiquette « Chez toi », ton travail = épingle bleue + « Ton travail », jamais masquées ; liseré lumineux au sol autour des deux bâtiments (`updateMarks`, or / bleu). Fiche du commerce v2 (`miniPlaceHTML`) : pastille Ouvert / Fermé avec l'heure (fin du dernier service du jour / prochaine ouverture), carte du poste avec bouton Postuler, pastilles des personnes en service (on les touche pour leur parler). Immeubles : soubassement, bandeau au-dessus du rez-de-chaussée, balcons filants (2e et dernier étage), lucarnes dans les toits (géométries sans uv et non indexées pour fusionner avec les toits Mansart).
